# BOZER NEURAL — Animation Studio

Un studio de préproduction pour développer l'anime original **BOZER NEURAL**.

## Démarrer

Ouvrir `index.html` dans un navigateur récent. Le studio fonctionne sans serveur ni dépendance externe.

## Modules du prototype

- Vue générale du projet
- Fiches personnages : création, modification et suppression
- Monde et lieux : création, modification et suppression
- Épisodes et découpage en scènes
- Sauvegarde locale automatique dans le navigateur
- Export et import des données au format JSON

## Données et confidentialité

Les données créées dans le studio restent dans le stockage local du navigateur utilisé. Elles ne sont pas synchronisées entre appareils. Utiliser régulièrement **Bibliothèque → Exporter les données** pour conserver une sauvegarde.

## Limites actuelles

Cette première version est un studio de préproduction interactif. Elle ne génère pas encore d'images, d'animation vidéo, de voix ou de montage final. Les prochains modules pourront ajouter storyboard, fiches de plans, bibliothèque de références visuelles et pipeline de production.

## Direction artistique

Futur 2050 lumineux et humain : architecture blanche/perlée, verre, jardins, montagnes, forêts et technologie discrète. Personnages naturels, expressifs et habillés sobrement. Le monde est futuriste ; les personnages ne doivent pas ressembler à des soldats SF permanents.
